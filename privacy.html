プライバシーポリシー

トレンドキーワード調査ツール ／ 制定日：2026年10月20日

1. 対象

このポリシーは「トレンドキーワード調査ツール」（以下「本ツール」）での情報の扱いを定めます。本ツールは運営者本人だけが使う個人用のツールで、第三者の利用者はいません。

2. 取得する情報

  • Google 広告 API：運営者が指定したキーワードの月間検索数などの統計情報。個人を特定できる情報は含みません
  • Google ドライブ・スプレッドシート：運営者自身のファイルのうち、本ツールが使うファイルの読み書き

本ツールは、運営者以外の人の個人情報を取得しません。

3. 利用目的

取得した情報は、運営者がブログ記事のテーマを選ぶための調査だけに使います。

4. 保存場所

取得した情報は、運営者自身の Google ドライブ上のスプレッドシートに保存します。それ以外のサーバーには保存しません。

5. 第三者への提供

取得した情報を第三者に販売・提供・共有しません。広告配信やその他の目的に転用しません。

6. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用と移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

7. 削除

保存した情報は、運営者がスプレッドシートから削除することで消去できます。本ツールへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

English summary

This tool is used only by its owner. It reads keyword statistics from the Google Ads API and reads/writes the owner's own files in Google Drive. It collects no personal data about other people, stores data only in the owner's Google Drive, and never sells or shares it. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
